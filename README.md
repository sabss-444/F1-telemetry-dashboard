# F1-telemetry-dashboard
A python bases Formula 1 telemetry analysis and visualisation project designed to explore and compare driver performance using real F1 session data.

The project will use telemetry and timing data to investigate how drivers gain and lose time around a circuit, with a focus on speed, braking, throttle, gear changes, lap times, and other performance metrics.

The long term goal is to turn the analysis into an interactive dashboard where users can select a race, session, driver, and lap and explore the telemetry themselves.  

------------------------------------------

# Project Goals

The main goals of this project are to:
* Work with real-world Formula 1 telemetry data
* Develop my python and data analysis skills
* Learn how to process and clean motorsport data
* Visualise telemetry data using interactive graphs
* Compare the performance of different drivers
* Investigate where lap time differences occur around a circuit
* Build an interactive dashboard for exploring F1 data
* Develop a portfolio project combining data science and motorsport

-----------------

# Planned Features

### Telemetry analysis
the project will analyse telemetry such as:
* Speed
* Throttle
* Brake
* Gear
* RPM
* DRS / aerodynamics mode data where applicable
* Distance around the circuit
* Lap time

### Driver comparisons
The dashboard will eventually allow comparisons between drivers, including:
* Lap times
* Sector times
* Speed traces
* Braking points
* Corner entry speed
* Minimum corner speed
* Corner exit performance
* Lap time differences

### Data visualisation
planned visualisation include:
* Speed vs. distance
* Throttle vs. distance
* Brake vs. distance
* Gear vs. distance
* Driver speed comparisons
* Lap time delta
* Circuit/track visualisations
* Sector and corner analysis

# Technologies

The project is being developed primarily in Python.
Planned technologies include:
* Python - core programming language
* FastF1 - F1 timing and telemetry data 
* Pandas - data manipulation and analysis
* NumPy - numerical calculations
* Matplotlib - initial data visualisation
* Plotly - interactive visualisation
* Streamlit - interactive dashboard
* Git & GitHub - version control and project development.

  It is also intended to demonstrate the ability to take real world data set, process it, analyse it, communicate findings visually, and develop the analysis into an interactive application.
